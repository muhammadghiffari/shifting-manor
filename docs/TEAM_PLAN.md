## Part 5. Assets: who makes what

The game runs with placeholders, so assets never block you. Work in priority order P0 → P1 → P2 (see `ASSETS.md`).

| Need | Best source | Notes |
|---|---|---|
| Sprites, tiles, key art | A dedicated image-generation tool (Astra or another image model) with the style bible in `ASSETS.md`, then manual cleanup | General chat models that only understand images do not draw sprites. Text-to-image tools do, but need palette snapping and cleanup for consistent pixel art |
| UI icons, marks, simple shapes | Hand-drawn pixel art in an editor (Aseprite, LibreSprite, Piskel) or generated by code | Small and simple, so consistent style is easy |
| Placeholder sprites and checks | The coding agent can generate coloured placeholders, snap palettes, build a contact sheet and validate sizes with scripts | Good for tooling and QA, not for final art |
| SFX | Free CC0 libraries (Kenney, OpenGameArt, Freesound CC0) or synthesised by script | Put credits in `assets/CREDITS.md` |
| Music | Free CC0 music or a music-generation tool | Keep calm and tense layers the same tempo and length |
| Fonts | Silkscreen / VT323 (open licenses) | Include license files |

Quality gate before anything enters `assets/`: correct size and frame count, palette matches `ASSETS.md`, transparent background, file name matches the manifest key, entry added to `assets/CREDITS.md` (flag AI-generated files).

## Part 6. Explain-back checkpoints (so both of you can answer the lecturer)

The code is written mostly by an agent, but you are graded on understanding. Before each rehearsal each person must be able to answer, without notes:

1. What are the facts, and what is one IF–THEN rule in plain words?
2. What does forward chaining do, step by step, with one example from a real run?
3. Why forward and not backward chaining here?
4. What does the enumeration add that rules alone miss? Give the overlapping-Breeze example.
5. What is a *frontier* cell, and why cap it at 14?
6. How is risk computed, and why is the pit count part of it?
7. What does R16 do, and what goes wrong if you skip it (B2)?
8. What does the A* cost function optimise?
9. Why is RL not the core? When could it help?
10. What did the simulation show, and what are its limits?

Also: each of you must run the game and the CLI demo yourself at least twice, and each presents the part the other built (Ghiffari explains the UX decisions, Radithia explains the AI). Keep the commit history and `DECISIONS.md`. Check your course policy on AI-assisted work and disclose tool use the way the course requires.

| Problem | What to do |
|---|---|
| CI red | Read the log, ask the agent to fix; do not merge red |
| Agent proposes a big new feature | Check PRD Section 10; if it is not Must, write it in a Could list and move on |
